# Webapp Technologies Pathway

### Where are we at now

- we'll be developing web apps using Angular
- but before angular we need to build the tech stach first.
- need to work on client side and server side now.

### Steps:
1. intro to JS
2. intro to Node.js and simple server side JS code
3. Add npm packages (express.js) to server side and create a web server that responds to requests as an endpoint.
4. Create client HTML page taht requests data from node server using jQuery framework to execute AJAZ calls to the server.
5. intro to TypeScript (compiled, used in Angular).
6. intro to Angular templating and structural directives to develop single page web apps (instead of plain JS and jQuery)
7. Link client side Angular app with Node.js server for communication.
8. Intro to Sockets.io package to enable real time bi-directional clien-server communicaitons.
9. Intro server side Database (mongo.db)
10. Add an npm package to Node.js server to query a mongo.db and provide results as response to a client request.
11. Intro to app testing methods (Unit, Integration?, End2End)
