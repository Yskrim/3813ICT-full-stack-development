# About
This is a structured history version of 3813ICT Web Application Development course

### Structure
- I decided to separate each week's modules onto their own branches that I will try to keep pushed to the remote too, but can't guarantee I'll remember to. 
- Each week's branch is then subdivided into it's own lecture and workshop branches.
- Each individual branch is responsible for it's own task/feature/topic.
- Each child branch is being merged to it's parent with --no-ff flag, signifying the merge action is also going to be tracked in history, acting as a confirmation of completion of the task/feature/topic. This is also true for the weekly branches that will be merged into the main as long as the course goes.
