# Workshop 9. Уточнения к заданию

Исходник — *Workshop 9.pdf*. Эта заметка сохраняет цель практики, одновременно уточняя места, где формулировки требуют осторожного применения.

## Повторный запуск и очистка данных

Задание предлагает удалять коллекцию `products` перед каждым запуском, чтобы избежать дублей. Это допустимо только для изолированной учебной базы и когда действительно нужно начать с чистого состояния. Удаление коллекции уничтожает все документы и индексы; не запускай такую команду против базы с нужными данными.

Для повседневной отладки безопаснее использовать отдельную БД `workshop9_dev`, удалять только специально созданные тестовые записи или добавить явную команду reset, которую запускают осознанно.

## Схема и уникальность

Сохрани типы из задания: числовой `id`, строковые `name` и `description`, числовой `price`, целый `units`. Уточни правила для нулевых значений и обязательности описания у преподавателя, если они важны для оценивания.

Простая проверка количества документов с таким `id` перед вставкой подвержена гонке. Создай уникальный индекс и всё равно покажи пользователю понятное сообщение при конфликте. Подробное объяснение — в [поправках к 9.3](../materials/9_3-product-crud-app-popravki.md#p-3).

## Актуальные версии инструментов

В слайдах и старом шаблоне могут быть callback-вызовы MongoDB. Актуальный MongoDB Node.js Driver начиная с версии 5 не поддерживает callbacks: используй `async/await`.

Для Express разбирай JSON через `express.json()`. Для Angular следуй версиям проекта: новые конфигурации предоставляют `HttpClient` через `provideHttpClient()`, а шаблонные формы требуют `FormsModule`.

## Отладка API до Angular

Проверь сервер самостоятельно: статус, заголовок и тело ответа на каждый маршрут. Это позволяет отделить проблему API от проблемы Angular. Следи, чтобы Express и клиент использовали одинаковые пути, HTTP-методы, имена полей и адрес сервера.

## Демонстрация и оценивание

В PDF упомянута демонстрация преподавателю и доля оценки 2.5%. Это может относиться к конкретному запуску курса. Проверь актуальные требования, дедлайн и формат в LMS или у преподавателя.
