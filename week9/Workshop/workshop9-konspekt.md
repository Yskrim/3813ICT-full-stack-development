# Workshop 9. CRUD-приложение для товаров

**Источник:** *Workshop 9.pdf*  
**Связанные файлы:** [примеры и план реализации](workshop9-primery.md) · [вопросы](workshop9-voprosy.md) · [ответы](workshop9-otvety.md) · [заметки к заданию](workshop9-popravki.md)

## Что предстоит собрать

В лекциях мы уже прошли путь от Node-драйвера MongoDB к Express API и Angular-клиенту. Практика объединяет эти навыки в небольшой каталог товаров: сначала консольные операции с базой, затем HTTP-маршруты, затем интерфейс.

В документе товара используются поля `id`, `name`, `description`, `price`, `units`. По описанию задания `id` — числовой, цена — число, количество — целое. MongoDB дополнительно добавляет `_id`; см. разницу в [конспекте 9.3](../materials/9_3-product-crud-app-konspekt.md#1-модель-товара-и-два-вида-идентификаторов).

## Этап 1. Node.js и MongoDB

Создай репозиторий Git и проект Node.js. Вынеси работу с данными в отдельные модули добавления, чтения, изменения и удаления. Проверь каждый модуль отдельно, чтобы убедиться, что он действительно меняет ожидаемый документ в правильной коллекции.

Затем собери операции в `app.js` и проверь полный CRUD-цикл. В текущем драйвере MongoDB используй Promise/`async` API; не копируй callback-вызовы со старых слайдов. Подробный пример — в [материале 9.1](../materials/9_1-node-mongodb-konspekt.md).

## Этап 2. Express API

После проверки функций базы подключи Express и выдели маршруты. Сначала сделай серверные ответы понятными и проверь их без Angular. Сверь названия URL и HTTP-методов между клиентом и сервером.

Валидация должна быть на сервере. Если `id` продукта должен быть уникальным, защити его уникальным индексом MongoDB, а не только проверкой перед вставкой. Пример связки — в [конспекте 9.3](../materials/9_3-product-crud-app-konspekt.md).

## Этап 3. Angular-клиент

Собери список товаров, форму добавления и страницу редактирования. Вынеси запросы в Angular-сервис; для формы используй `FormsModule`, для HTTP — `HttpClient`. Отображай результаты и ошибки запросов, а после CRUD-действий обновляй список.

Как мы уже знаем из [темы Observable недели 6](../../week6/materials/6.1%20-%20Observables.pdf), `HttpClient` возвращает Observable, и ответ обрабатывается после подписки. В [материале 9.2](../materials/9_2-mongodb-express-angular-konspekt.md) разобрана связь сервиса с Express.

## Как понять, что работа готова

- Все четыре операции проверены на реальных документах в учебной базе.
- Express-маршруты дают согласованные ответы при успехе и при ошибках.
- Angular показывает товары и позволяет добавить, изменить и удалить их через API.
- После обновления страницы данные загружаются из MongoDB, а не только остаются в памяти компонента.

Требования к демонстрации и оцениванию могут зависеть от текущей организации курса. Уточни дедлайн и формат у преподавателя или в актуальной LMS.
