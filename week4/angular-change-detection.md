## Change detection

Приложение на Ангулар одностраничное (index.html). В нем предусмотрен state в котором компоненты добавляются/меняются/удаляются.

Zone.js -- механизм ангулар, который позволяет отслеживать стейт, реагируя на события и другие асинхронные действия.

Ангулар абстагирует большую часть ручных манипуляций ДОМ.

## Zone.js

monkey-patch -- zone.js подменяет стандартные асинк вызовы и после их выполнения, сообщает ангулар, что можно запустить change detection.

Ангулар обходил дерево компонентов и обновлял шаблоны, в которых данные изменялись.

Минус - проверка часто глобальная - пересматриваются несвязанные части приложения. При частых событиях - это дает лишнюю нагрузку.

Поэтому ангулар ушел от zone к signals и zoneless-режиму. Обновления стали локальными и точечными, без обхода всего дерева после каждого асинк события.

## Signals

Сигналы - реактивные примитивы, вроде обзервабл значений, отслеживают чтение и запись. Когда значение сигнала меняется, он автоматически говорит об этом зависимым потребителям сигналов (signal consumers).

С сигналами определять изменения стало чистым и локальным, а не глобальным.

Реактивное программирование - это как конвеер, двигает и трансформирует данные через пайплайн, реагируя на каждый триггер изменений. Мы подписываемся к потоку/пайплайну и когда происходит изменение значения, сразу появляется уведомление об изменении.

Это позволяет более тонко обновлять стейт страницы без обхода всего ДОМ.

Сигналы Ангулар это легковесные обертки для значений, передающие изменения во все зависимые компоненты.
Чтение значения сигнала происходит через функцию геттер, которая позволяет ангулару еще и следить, где сигнал используется.

Сигналы могут быть либо writable либо read-only.

## Creating, Reading and Updating a Signal()

Пример в проекте: `week4/angular-signals/signals`

```ts
import { signal, computed } from '@angular/core';

// создать writable signal
const name = signal('Allan');
const count = signal(0);

// прочитать (getter)
console.log(name()); // 'Allan'

// записать новое значение
name.set('Jesper');

// обновить на основе старого
count.update((n) => n + 1);

// computed — read-only, пересчитывается сам
const greeting = computed(() => `Hello, ${name()}!`);
const doubled = computed(() => count() * 2);
```

В шаблоне тоже через `()`: `{{ name() }}`, `{{ greeting() }}`.

Я описал все действия, происходящие на странице и методы классса, которые эти действия обрабатывают
В целом концепт понятен:
- сигнал - это функция, которая возвращает в класс стартовое значение, вместо прямого значения как обычно 
- computed() это новый сигнал, собирающий новое значение из того, что хранится в конкретном signal(). В примере он сразу принимает коллбек, который возвращает удвоенное число из числа кликов.
- метод .set() записывает новое значение в сигнал
- метод .update() использует прошлое значение, чтобы создать новое
