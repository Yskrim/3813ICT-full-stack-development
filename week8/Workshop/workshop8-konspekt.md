## Цель работы

В [8.1](../materials/8_1-nosql-konspekt.md#s3) мы разобрали документную модель, а в [8.2](../materials/8_2-mongodb-konspekt.md#s4) познакомились с CRUD. Теперь выполним эти действия для небольшой книжной лавки: создадим `bookStore`, сохраним книги и выполним поиск, обновление, удаление и сортировку.

Workshop просит документировать использованные команды в Word. Поэтому после каждого шага сохраняй команду и результат/краткое пояснение, чтобы можно было показать ход работы.

## Структура записи

В задании указаны поля `Id`, `Name`, `Price`, `Description`, `Category`. В MongoDB идентификатором служит `_id`; остальные поля удобно записывать, например, как `name`, `price`, `description`, `category`.

```js
{
  _id: 'book-01',
  name: 'JavaScript: The Good Parts',
  price: 45.00,
  description: 'A programming book (sample description)',
  category: 'programming'
}
```

Цены и краткие описания ниже — учебные значения. В задании найди реальные названия книг для выбранных категорий и подставь их; не выдавай примерные цены за фактические.

## Задание 1. Установить и запустить MongoDB

Установи Community server или подготовь облачное подключение согласно актуальным инструкциям. Запусти сервер, если он не работает как служба, затем открой `mongosh`. Старый `mongo` из задания уже заменён. Сверяй шаги по своей ОС и версии: исходная macOS-инструкция устарела.

## Задание 2. Создать базу и коллекцию

```js
use bookStore
db.createCollection('books')
```

`use` выбирает базу по имени. Явная команда коллекции делает следующий шаг очевидным; MongoDB может создать коллекцию автоматически при первой вставке.

## Задание 3. Добавить не менее пяти книг

Добавь минимум пять книг из двух или более категорий. Сохрани команды, затем проверь документы через `db.books.find().toArray()`.

## Задание 4. Выполнить CRUD и запросы из листа

Сделай и задокументируй девять действий:

1. Вставь пять или больше книг из двух категорий.
2. Удали один выбранный документ по точному `_id` или другому уникальному условию.
3. Обнови одно поле существующей книги через `$set`.
4. Найди и покажи все книги.
5. Найди все книги, отсортированные по имени.
6. Найди все книги из одной категории.
7. Найди книгу с максимальной ценой.
8. Выведи точное количество книг.
9. Покажи все книги только с именем и ценой.

Команды должны выполняться на текущем состоянии коллекции: после удаления и обновления результаты отражают изменённые данные. Для максимума отсортируй `price` по убыванию и ограничь вывод одной записью. Для проекции исключи `_id`, если нужны строго только два пользовательских поля.

## Как оформить документ сдачи

Для каждого пункта сохрани:

- номер и цель действия;
- команду `mongosh`;
- результат или короткое пояснение ожидаемого результата;
- для удаления/обновления — критерий, который показывает, какой документ затрагивается.

Перед записью проверь фильтр отдельным `find()`. Не запускай `deleteMany({})` и не удаляй базу вместо одного документа. Остальные рекомендации и полный согласованный пример — в [файле примеров](workshop8-primery.md).
