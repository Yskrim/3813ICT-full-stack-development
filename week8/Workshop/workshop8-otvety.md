# Workshop 8 — каталог книг: ответы с объяснениями

**Источник:** `Workshop 8.docx` (фактически PDF-документ)  
**Связанные файлы:** [план работы](workshop8-konspekt.md) · [примеры](workshop8-primery.md) · [вопросы](workshop8-voprosy.md) · [поправки](workshop8-popravki.md)

1. ID, Name, Price, Description и Category. В MongoDB ID удобно хранить в `_id`, а имена прикладных полей — например, `name`, `price`, `description`, `category`.
2. `_id`. Если не задать его явно, MongoDB создаст ObjectId.
3. `use` переключает текущий контекст по имени, но не обязательно материализует базу. Она появляется после создания коллекции или записи.
4. `db.books.insertMany([document1, document2, ...])`.
5. `db.books.deleteOne({ _id: выбранныйId })`, при условии что фильтр указывает именно на требуемый документ.
6. Чтобы убедиться, какой документ совпадает, и избежать удаления не той записи.
7. `db.books.find().sort({ name: 1 })`.
8. `db.books.find().sort({ price: -1 }).limit(1)`. Если есть несколько книг с одинаковой максимальной ценой, такой запрос показывает только одну из них.
9. `db.books.countDocuments({})`.
10. `db.books.find({}, { name: 1, price: 1, _id: 0 })`.
11. Запросы выполняются после мутаций, если задание описывает последовательность вставки, удаления и обновления. В примере после вставки шести и удаления одной ожидается пять.
12. Сохрани команду и фактический результат каждого из девяти пунктов в Word-документе. Убедись, что результаты соответствуют состоянию твоей базы.

Разбор всех операций и их ожидаемый результат есть в [полном примере](workshop8-primery.md).
