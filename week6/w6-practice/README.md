# 3813ICT — Неделя 6: практика на один вечер

Неделя 6 о том, как приложение реагирует на события, которые приходят когда угодно: нажатия, ответы сервера, сообщения других пользователей. Теория длинная — от паттерна Observer до комнат Socket.IO, — но главное из неё помещается в один вечер практики. К концу вечера у тебя будет чат, в котором сообщение из одной вкладки мгновенно появляется в других, а пользователи разделены по каналам.

Заданий четыре, от простого к сложному. Первые два — короткие опыты с Observable и Promise, чтобы механика стала понятной «в руках». Вторые два — рабочие куски Phase 2: чат на сокетах и каналы через комнаты.

## Как работать

1. Прочитай «Задачу» — там объяснено, какую проблему решает задание и почему именно так.
2. Выполни «Старт», потом «Что сделать» по частям.
3. Перед каждым опытом **сначала запиши предсказание**, потом запускай. Наблюдения — в `observations.md`.
4. Застрял — «Наводящие вопросы», потом ссылки из «Материалов».
5. Проверь себя по «Критериям готовности» и пришли решение в чат: код, `observations.md` и ответы на вопросы из критериев.
6. Только после этого открывай «Сверку после попытки».

Отвечай по памяти; если не знаешь — пиши «не знаю».
