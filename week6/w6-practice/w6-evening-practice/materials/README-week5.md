## Как работать

1. Прочитай конспект темы. Значок ⚠ П-N ведёт в поправки, если хочется понять, чем материал курса отличается.
2. Посмотри примеры — это готовые опорные куски для Phase 2.
3. Ответь на вопросы по памяти, потом сверься с ответами. Ошибочные вопросы повтори через день.

Темы связаны: 5_6 собирает 5_1–5_5 в один сценарий входа, поэтому её удобнее читать последней.

## Как открыть

- **VS Code:** открой папку, файлы смотри в превью (`Ctrl+Shift+V` / `Cmd+Shift+V`). Ссылки прыгают прямо к нужному разделу. Для диаграмм нужно расширение **Markdown Preview Mermaid Support**.
- **Obsidian:** диаграммы рендерятся сами; ссылки на разделы откроют нужный файл (без прокрутки к разделу).
- Все файлы должны лежать в одной папке — ссылки между ними относительные.

## Чего здесь нет

Модули Node, npm, «голый» HTTP-сервер, Express и REST — это материалы недели 3 (файлы серии 3_x). Здесь они используются, но не разбираются отдельно.
