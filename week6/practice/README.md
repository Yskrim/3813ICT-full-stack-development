# Week 6 — практика

18 заданий по шести темам, строго по конспектам из `week6/*.md`. Ничего, чего нет в конспектах, здесь не требуется: никаких `switchMap`, `mergeMap`, `combineLatest` и прочего, что мы не разбирали.

Цель — не «пройти задания», а суметь потом написать проект самому. Поэтому решений в репозитории нет специально.

## Установка

```bash
cd week6/practice
npm install
```

## Как запускать

Node 26 умеет запускать TypeScript напрямую, сборка не нужна:

```bash
node 01-observer-pattern/task-1-subject.ts
```

Серверные задания запускаются через npm-скрипты (см. `package.json`):

```bash
npm run sockets:1     # эхо-сервер, тема 04
npm run rooms:1       # комнаты, тема 06
```

**Важное ограничение.** Node в режиме strip-only не поддерживает два вида синтаксиса TypeScript, и мы на это уже наступали: параметры-свойства `constructor(public name)` и `enum`. Пиши поля явно:

```ts
class Observer {
    name: string; // так работает
    constructor(name: string) {
        this.name = name;
    }
}
```

## Порядок и метод

Темы идут по нарастающей и опираются друг на друга, поэтому по порядку: `01` → `06`. Внутри темы задания тоже по нарастающей.

Правило, которое стоит соблюдать ради собственной пользы: **сначала предскажи вывод, потом запусти**. Записал ожидание, запустил, сравнил. Если не совпало — ищи причину в своей модели, а не подгоняй код, пока не заработает. Именно расхождение между ожиданием и реальностью и есть обучение.

## Что считать выполненным

В README каждой темы у задания есть блок «Критерии» и блок «Ожидаемый вывод». Задание сделано, когда выполнены все критерии и вывод совпадает по смыслу (не обязательно дословно по формулировкам сообщений).
