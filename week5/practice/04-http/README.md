# Тема 4 — HTTP-запросы

Теперь у приложения есть связь с сервером, и можно наконец перенести данные туда, где им место. Главный инструмент — `HttpClient`, а главная новая идея — Observable: запрос отвечает не сразу, и код должен уметь ждать, не замораживая страницу. В этой теме ты сначала потрогаешь Observable без всякого сервера, а потом переведёшь группы и сообщения чата на настоящие запросы.

**Результат темы:** группы и сообщения чата живут на сервере; Angular получает, создаёт, переименовывает и удаляет их, подгружает сообщения порциями и автоматически подписывает каждый запрос пользователем.

**Время на тему:** около 3–3.5 часов.
