# Тема 2 — Сервисы и DI

В теме 1 ты уже написал два сервиса, почти не задумываясь, как Angular их создаёт и почему все компоненты получают один и тот же объект. Здесь разберёмся с этим механизмом по-настоящему — внедрением зависимостей — и используем его, чтобы разложить логику чата по сервисам: состояние каналов, текущий пользователь, проверка прав.

**Результат темы:** сервис состояния каналов, которым пользуются несколько компонентов, и `AuthService` с гардами, закрывающими маршруты по ролям.

**Время на тему:** около 2.5–3 часов.
