### ЧАСТЬ Б: - один экземпляр сервиса.

- service is provided by the root
- only one id is logged in the console.
- all instances of related components interact with the singleton service
    - multiple displays return the same service id
    - all buttons increment and reset the same shared counter

### ЧАСТЬ В: - несколько экземпляров.

Для CounterButtonComponent я задаю свой сервис через providers: [CounterService] и inject
В результате: 
  - для кнопки создается свой инстанс сервисаб это я узнаю через консоль, пишет два разных айди.
  - При нажатии на кнопку, дисплей не меняется, потому что он все еще привязан к основному сервису.
  - Дисплей все равно привязан к корневому сервису, второй инстанс все еще меняет оба дисплея.

Для CounterDisplayComponent я задаю свой сервим через new CounterService.
В результате: 
  - теперь консоль выводит три айди.
  - кнопка не меняет дисплей
  - дисплей не меняется при действиях на правильном компоненте ниже

### Вопросы

  - Создается когда компонент монтируется
  - Уничтожается когда компонент демонтируется

Ты можешь ответить: назови три места, где inject() работает, и одно, где нет
- работает в инициаторе поля класса
- работает в конструкторе
