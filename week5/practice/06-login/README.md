# Тема 6 — Вход целиком

Все части уже на месте: хранилище, `AuthService` с гардами, связь с сервером, перехватчик. Не хватает одного — настоящего входа. Пока пользователь «входит», выбирая себя кнопкой, и сервер ему просто верит. В этой теме ты напишешь проверку пароля на сервере, подключишь к ней форму входа и дашь пользователю редактировать профиль, который сохраняется в файл на сервере.

**Результат темы:** полный поток входа, как в Phase 2: форма → сервер проверяет пароль по файлу → профиль без пароля приходит в браузер → гарды и перехватчик работают с настоящим пользователем.

**Время на тему:** около 3–3.5 часов.
