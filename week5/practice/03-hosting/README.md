# Тема 3 — Хостинг и CORS

До сих пор Angular и Express жили каждый сам по себе. Пора их соединить — и тут браузер начнёт мешать: страница с одного адреса не может просто так читать ответы с другого. В этой теме ты увидишь, почему так, и освоишь три способа жить с этим: разрешить через CORS, обойти прокси при разработке и собрать всё на одном сервере для сдачи.

**Результат темы:** настроенные режимы разработки и сборки — те самые, в которых будет работать Phase 2.

**Время на тему:** около 1.5–2 часов.
