# Тема 1 — Хранилища браузера

Пока приложение живёт только в памяти JavaScript, любое F5 стирает всё: кто вошёл, что было открыто, что набрано. В этой теме ты научишься сохранять состояние в браузере так, чтобы оно переживало перезагрузку, и выбирать подходящее хранилище под задачу.

**Результат темы:** сервис для безопасной работы с localStorage и «сессия» пользователя, которая переживает F5 и синхронизируется между вкладками. Это основа будущего `AuthService`.

**Время на тему:** около 2–2.5 часов.

**Материалы:** [конспект 5_1](../materials/5_1-data-persistence-konspekt.md) · [поправки 5_1](../materials/5_1-data-persistence-popravki.md) · [вопросы 5_1](../materials/5_1-data-persistence-voprosy.md)
