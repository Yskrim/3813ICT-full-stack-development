# Node + Express + CORS — практика

5 заданий по нарастающей сложности. Каждое — отдельный мини-проект со своим
`package.json`, чтобы можно было делать `npm install` и `npm run dev` в каждой
папке независимо.

Порядок:

1. **01-basic-server** — базовый Express-сервер, статика, один JSON-роут.
2. **02-rest-api** — полноценный REST API (CRUD) поверх массива в памяти.
3. **03-cors-problem** — воспроизвести реальную CORS-ошибку и починить её.
4. **04-cors-config** — тонкая настройка `cors()`: конкретный origin, методы,
   preflight на `PUT`/`DELETE`.
5. **05-login-cors-client** — мини-версия Workshop 5 без Angular: сервер с
   `/api/auth` + отдельный HTML/JS клиент на другом порту.

## Как работать

- Открой `TASK.md` в папке задания — там цель, требования и как проверить себя.
- В `server.js` расставлены `// TODO:` — решение пишешь сам.
- Никаких файлов с готовым решением нет специально — если запутался, зови меня,
  разберём вместе, а не подглядывай в файл.
- Проверяй руками: `curl` в терминале и/или консоль браузера (вкладка Network,
  вкладка Console для CORS-ошибок).

## Общие команды в каждой папке

```bash
npm install
npm run dev     # nodemon server.js
# или
npm start        # node server.js
```
