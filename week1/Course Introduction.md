### Learning objectives:
1. Analyze the configuration requirements for async web servers, setup environments via emts(environment management tools) like package managers and build tools
2. Create server-side async applications that can handle multiple simultaneous client requests
3. Create front-end interfaces using a modern MVC framework that can dynamically communicate with an async web server app.
4. Apply testing strategies and e2e tests to ensure software quality.
5. Evaluate web and storage scenarios to devise the correct architectural approach for specific requirements

### Tech Stack:
The **MEAN** stack is used for dynamic  web apps
- M = Mongo DB = database
- E = Express = backend
- A = Angular = frontend
- N = Node.js = js for backend (run on Google V8 engine)
